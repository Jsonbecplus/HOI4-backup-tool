# 程序介绍

这是一款专门为《钢铁雄心4》游戏设计的轻量型存档备份工具，基于GTK4框架开发，原生适配Windows系统，能够帮助玩家自动、高效地管理游戏存档备份，避免因游戏崩溃、操作失误等问题丢失游戏进度，支持铁人模式存档的特殊处理，是硬核玩家的实用辅助工具。编译相关请转到[这里](https://github.com/Jsonbecplus/HOI4-backup-tool/blob/main/source/README.md "o(TヘTo)") 。

# 核心功能特性
## 1. 双模式备份适配不同游玩场景

工具提供两种备份模式，覆盖普通游玩与铁人游玩的不同需求：

**普通模式‌**：自动扫描存档目录下所有后缀为.hoi4的存档文件，默认开启“过滤游戏内备份”功能，自动识别命名格式为*_YYYY_MM_DD_HH.hoi4的游戏原生自动备份文件，跳过这类文件的备份操作，进一步减少重复备份带来的资源浪费。自动按存档的基础名称分组，仅选择每组中修改时间最新的文件进行备份，避免同一系列存档产生大量冗余备份文件。

**非铁人模式‌**：针对性仅备份游戏的autosave.hoi4自动存档文件，在保证进度安全的同时最大程度降低磁盘占用。

针对铁人模式带有前导空格的特殊命名存档，工具内置专属处理逻辑，可自动识别并去除文件名前的多余空格，正常完成备份与还原操作。

## 2. 灵活的自动备份机制
支持自定义自动备份间隔，可在1分钟到1440分钟（24小时）的范围内自由调整，满足不同节奏的游玩存档需求。
自动备份任务在后台线程执行，不会阻塞主界面操作，备份过程中实时更新状态栏提示，操作流畅不卡顿。
## 3. 智能备份数量管理

用户可自定义单组存档的最大备份保留数量（1-100份区间可选）(没错是每个存档都保存“最大备份保留数量”不是某个存档)，当同一系列存档的备份数量达到上限时，工具会自动识别并删除最旧的历史备份，始终保留最新的指定份数备份，避免备份目录无限制膨胀占用磁盘空间。

## 5. 存档还原

还原时会删除备份时加上的时间戳，并覆盖游戏存档目录的文件。

例：xby200268211003.hoi4 还原后会被重命名为xby.hoi4

## 6. 高度可自定义的目录配置

工具默认自动定位系统当前用户的《钢铁雄心4》默认存档路径，同时支持用户自由修改备份文件的存储目录，可将备份文件放置到非系统盘等更安全的位置，进一步降低数据丢失风险。

# 运行环境说明
运行平台：原生适配Windows系统
编码适配：全界面采用UTF-8编码，完美支持中文路径与中文文件名显示，无乱码问题
# 基础使用流程
启动程序后会自动识别当前系统用户名，定位到《钢铁雄心4》的默认存档目录，自动在该目录下创建hoi_backups文件夹作为默认备份存储路径。
根据游玩需求选择对应的备份模式，调整自动备份间隔、最大备份保留份数等参数。
勾选启用自动备份后，工具将在后台按设定的时间间隔自动执行备份任务，状态栏会实时显示最新操作状态。
在下方列表中选中需要还原的历史备份，点击“还原选中备份”即可快速将存档恢复到对应备份时间的状态，还原完成后会自动弹窗提示操作结果。
若修改过备份目录存储位置，点击“刷新列表”即可重新扫描目录更新所有备份文件的展示。
